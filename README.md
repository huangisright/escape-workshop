# 密室工坊 v4｜部署與使用說明

共有兩個程式檔：`Code.gs`（後端）和 `Index.html`（畫面）。部署一次大約需要 15 分鐘，之後老師和學生只要有網址或 QR code 就能用。

---

## 一、第一次部署（約 15 分鐘）

**請用個人 Gmail 帳號，不要用學校帳號。** 學校帳號通常會限制「所有人都能存取」，學生沒有帳號就進不來。

1. 打開 <https://script.google.com>，按「新專案」，把專案名稱改成「密室工坊」。
2. 把左邊 `程式碼.gs` 裡的內容全部刪掉，貼上 `Code.gs` 的全部內容，按儲存。
3. 按左邊「檔案」旁的 ＋ →「HTML」，檔名輸入 **Index**（大寫 I，不要加 .html），把內容換成 `Index.html` 的全部內容，按儲存。
4. 上方的函式選單選 **setup**，按「執行」。
   - 跳出授權時：選你的帳號 →「進階」→「前往 密室工坊（不安全）」→「允許」。這是因為這支程式是你自己寫的、沒有送 Google 審查，不是真的不安全。
   - 執行完，下方「執行紀錄」會顯示 **管理者代碼**（A 開頭的 7 碼），請記下來。
   - 雲端硬碟裡會多出一個「密室工坊」資料夾，資料庫試算表、學生上傳的檔案、匯出檔都在裡面。
5. 右上角「部署」→「新增部署作業」→ 齒輪圖示選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 用瀏覽器打開這個網址，輸入管理者代碼，就進到管理頁。
7. 管理頁 →「設定」→「平台網址」貼上同一個網址（結尾 `/exec`）→ 儲存設定。QR code 都用這個網址產生。新版編輯器有時自動抓到的是「程式庫」網址（`/macros/library/…`），那種網址打不開，所以請一定要填。

忘記管理者代碼：在編輯器選 `showAdminCode` 執行，看執行紀錄。

## 二、之後更新程式（網址不變）

把新版程式貼上、儲存後：「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」。**不要按「新增部署作業」**，否則會產生新網址，舊的 QR code 就失效了。

## 三、老師團隊出題（現在就能開始）

1. 管理頁 →「代碼」→ 在「新增老師」一行輸入一位 → 建立老師代碼。
2. 按「列印代碼 QR」，把每位老師的代碼或 QR 交給他。
3. 老師掃 QR 或輸入代碼 →「新增一題」→ 依序填完 7 個區塊。全部自動儲存，上方檢核亮綠燈就完成。
   - 老師可以看到其他老師的題目（唯讀），避免撞題。
   - 老師多了「科學依據」和「換皮檢核」兩欄必填。
4. 管理者 →「示範密室與題庫」→ 建立示範密室 →「挑題與排序」→「封面、說明、結局」填好。
5. 「總覽與審核」→ 示範密室的「試玩」先自己走一遍 →「發布」→ 出現遊戲代碼和 QR。
6. 發布後老師再改題目，**不會影響正在玩的版本**；要讓新內容上線，就按「更新發布版本」。

## 三之一、示範密室的選用玩法（氣候變遷密室）

這三種玩法來自《氣候變遷密室逃脫・示範密室規劃草案》，只有老師的示範密室可以開，學生密室不受影響。都不開就是一般密室。

| 玩法 | 在哪裡設定 | 玩家看到什麼 |
|---|---|---|
| **終章碎片** | 「示範密室與題庫」→「封面、說明、結局」→ 勾「開啟終章」，寫終章頁；再到「挑題與排序」幫每一格填碎片 | 每解開一題拿到一塊碎片，放在線索簿；主線全解完進入終章，輸入碎片拼成的密碼才算逃脫 |
| **跳過扣時** | 同一頁的「跳過一題扣幾分鐘」（0 = 不能跳過） | 主線題目下方有「跳過這題」，扣時間但照樣拿到碎片；終章不能跳過 |
| **寶庫** | 「挑題與排序」→ 題庫裡按「放進寶庫」 | 逃脫後還有時間，就一題接一題玩寶庫；可以換下一題或結束遊戲 |

幾個規則：

- **碎片跟著位置走**：第 1 格的碎片給第 1 題，不管那一格放的是哪位老師的題目。調整題目順序時碎片不會跟著搬。
- **終章密碼**留白時，就是碎片依序接起來（例如碎片 7、3、1 → 731）；也可以自己填一個密碼。
- **逃脫時間**在解開終章的當下就定下來，包含跳過扣的時間；寶庫做多做少都不影響。時間到時還在寶庫，仍然算逃脫成功。
- 檢核會擋住：開了終章但有題目沒設碎片、沒寫終章頁、寶庫題目有紅燈。
- 「進行中」會顯示終章、寶庫進度和跳過次數；「數據」多了平均逃脫時間、每題跳過次數，寶庫題標成 V1、V2…。

## 四、營隊當天流程（學生）

| 時間 | 學生 | 你（管理頁） |
|---|---|---|
| 營隊前 | — | 「代碼」一次貼上六組（格式：`第一組：王小明、李小華、…`），列印各組 QR |
| 第一天：拆解範例 | 用遊戲代碼玩示範密室 | 「進行中」看各隊進度 |
| 第一天：製作 | 組長填「密室資訊」、上傳心智圖；每人新增自己的題目，先填步驟鏈 | 「總覽」看各組紅黃燈 |
| 第二天上午 | 完工 → 按「試玩整間」組內測試 → 修正 → **11:00 前按送審** | 「檢視」各組（含 HTML 原始碼洩題檢查）→「審核通過」或「開放修改」 |
| 第二天上午 | 依材料清單佈置教室 | 「列印材料清單」；在各組「編輯」→ 密室資訊填教室位置 |
| 第二天下午 | 各組帶一台 iPad 玩別組密室，結束後評難易度 | 各組「發布」→ 投影遊玩 QR；「進行中」監看 |
| 解密時刻 | — | 各組「數據」：預估 vs 實際時間、常見錯誤答案、評分、回饋 |
| 營隊後 | — | 「匯出」：一題一個 HTML 存檔；整間密室離線版 |

**營隊規則**（每人幾題、每題幾分鐘、提示幾層、答錯等幾秒）在「設定」分頁調整。超過規則只亮黃燈，不會擋住學生；只有紅燈（必填沒填）會擋送審。

## 四之一、玩家平板：重新整理與重置

- **重新整理不會掉進度**：平板會記住正在玩的遊戲，重新整理或關掉再打開同一個網址，會接著原本的題目，計時也照舊。
- **重置**：遊玩畫面右上角有「重置」按鈕。按下後這一隊的進度清掉、不列入數據，平板回到輸入隊名的畫面。已經逃脫、正在寶庫的隊伍，按重置只會結束寶庫，逃脫成績保留。
- **重置密碼**：怕學生自己按重置重來，可以到「設定」填「重置密碼」，按重置時要輸入（請關主保管）。空白就是不用密碼。
- **評分完**會出現「下一隊開始」，直接回到同一個密室的輸入隊名畫面。
- 「進行中」會把重置過的場次標成「已重置」。

## 五、正式上線前一定要做的實機測試

模擬環境已經跑過完整流程（後端 70 項、介面 21 項全部通過），但下面這幾件事只有在真的 Google 環境和學校的 iPad 上才能確認：

1. **iPad 上傳**：用學生的 iPad 拍照上傳、選相簿圖片上傳、上傳一個 GarageBand 匯出的 m4a。
2. **HTML 小遊戲**：上傳一個 HTML，在玩家畫面裡能不能正常玩。
3. **同時使用**：找 6 台 iPad 同時玩示範密室，同時另外幾台在改題目，看儲存速度。
4. **學校網路**：確認學校 Wi-Fi 沒有擋 `script.google.com` 和 `script.googleusercontent.com`。

以老師團隊的示範密室做這次測試最剛好。如果有任何一項不行，就退回 Holiyo：學生仍然用這個平台交件，檔案已經依組別和題號整理好，你轉傳也會比以前快。

## 六、已知限制

- 每個檔案上限 8 MB；圖片會在 iPad 上自動壓縮到長邊 1400 像素。
- Google 免費帳號的網頁應用程式，同時執行的請求數有上限。系統已經把儲存排隊處理，失敗會自動重試；但如果全部 27 人在同一秒狂按，儲存可能會慢幾秒。
- 匯出的「整間密室離線版」請用**筆電瀏覽器**開啟。iPad 從「檔案」App 直接開 HTML，不一定會執行程式。
- HTML 小遊戲的密碼寫在原始碼裡；營隊現場沒問題，但若要公開給校外玩，建議改成不顯示原始碼的設計。
- 答錯冷卻、提示時間都由伺服器判斷，玩家改不了；答案也不會送到玩家的平板上。
- 匯出的離線版 HTML 只有主線題目，不含終章、跳過和寶庫。

## 七、自動測試（改程式的人才需要）

`tests/` 裡用模擬的 Google 服務（試算表、雲端硬碟等）在電腦上跑 `Code.gs`，不用部署：

```
node --test tests/backend.test.js tests/climate.test.js tests/resume.test.js   # 後端
node --test tests/ui.test.js                                        # 介面（需要 Playwright 與 Chromium）
```

- `backend.test.js`：v4 原有的流程（代碼、謎題卡檢核、送審、上傳、發布凍結、遊玩、數據、匯出）。
- `climate.test.js`：終章碎片、跳過扣時、寶庫，以及舊版快照仍可遊玩。
- `ui.test.js`：在瀏覽器裡走一遍管理者設定 → 發布 → 玩家從頭玩到評分。
- `resume.test.js`：重新整理後接著玩、重置（含重置密碼）不列入數據。

模擬環境測不到的事（iPad 上傳、學校網路、多台同時使用）仍然要照第五節實機測試。
